# MVP - Catálogo de Utilidades (ODS 8)

Aplicação Web desenvolvida como Produto Viável Mínimo (MVP) para otimização e digitalização do comércio local de bairro, promovendo os princípios do **ODS 8 (Trabalho Digno e Crescimento Económico)**.

## 🚀 Tecnologias Utilizadas
* **Backend:** Python com Flask
* **Base de Dados:** SQLite via Flask-SQLAlchemy
* **Frontend & Estilização:** Tailwind CSS e Font Awesome
* **Controlo de Versão:** Git & GitHub

## 📂 Estrutura do Projeto
* `app.py`: Configuração principal do servidor, rotas e modelos da base de dados.
* `requirements.txt`: Dependências do projeto Python.
* `templates/`: Ficheiros HTML contendo as telas principais (`catalogo.html`, `carrinho.html`, `admin.html` e `base.html`).
